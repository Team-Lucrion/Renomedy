# Legacy Invite Cleanup

Future backend-generated beta and family invite codes use cryptographic randomness.

Before supervised family beta, revoke active beta invite codes that may have been generated before the randomness hardening.

Dry run:

```bash
node Backend/scripts/revoke-legacy-active-invites.js --before=2026-05-31T00:00:00.000Z
```

Apply:

```bash
node Backend/scripts/revoke-legacy-active-invites.js --before=2026-05-31T00:00:00.000Z --apply
```

The script:

- Requires `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` in `Backend/.env`.
- Is dry-run by default.
- Requires an explicit cutoff.
- Revokes only unused active beta invites created before the cutoff.
- Prints invite IDs and counts, not raw invite codes.

Family invite codes created before the hardening should be regenerated by sanctuary owners or through the existing admin/owner regeneration flow.
