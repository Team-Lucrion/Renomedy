Final User Journey

SIGNUP / LOGINUser opens app → LoginScreen→ Enters email + password (or Google OAuth)→ Clerk authenticates → JWT token stored

POST-AUTH ROUTINGAppNavigator detects isSignedIn=true→ Checks familyGroups.length→ If 0: OnboardingScreen→ If >0: MainTabs (drawer dashboard)

CREATE SANCTUARY (First-time user)OnboardingScreen → selects "Create New"→ Enters "The Sharma Sanctuary"→ Selects role: Caregiver→ Clicks "Create Sanctuary"→ Backend: creates family_groups row with auto invite code ABCD1234→ Backend: creates owner membership→ Backend: adds self as family_member→ AppNavigator: redirects to MainTabs

JOIN SANCTUARY (Invited user)OnboardingScreen → selects "Join Existing"→ Enters invite code ABCD1234→ Selects role: Patient→ Clicks "Join Sanctuary"→ Backend: validates code, checks expiry→ Backend: checks not already in sanctuary→ Backend: creates caregiver membership→ AppNavigator: redirects to MainTabs

SANCTUARY DASHBOARDFamilyScreen (renamed from FamilyScreen)→ Shows sanctuary name + invite code (with copy button)→ Shows member list with role badges→ Admin sees "Add Member", "Regenerate Invite" buttons→ Member sees read-only view

INVITE FAMILYAdmin taps "Regenerate Invite Code"→ Backend generates new code EFGH5678 + 30-day expiry→ Code displayed with "Copy" and "Share" buttons→ Family member joins via code (see step 4)

OCR + PRESCRIPTIONSUser navigates to Prescriptions tab→ Uploads prescription image→ Backend: Gemini Vision decodes text→ Backend: parses medications→ User verifies parsed data→ Medications added to schedule

MEDICATION MANAGEMENTTrackerScreen shows active medications→ Dose logging: taken / missed / skipped→ Refill alerts based on quantity remaining

PAYMENT / PREMIUMUser navigates to Pricing tab→ Sees Free / Care (₹199) / Family Plus (₹299)→ Taps "Protect Your Family" on Care plan→ Razorpay checkout opens→ User completes payment→ Webhook updates family_groups.subscription_status = 'active'→ Sanctuary-wide premium unlocked→ All members see premium features

NOTIFICATIONSOn first dashboard visit: permission prompt→ If granted: FCM token registered→ Scheduler sends medication reminders→ User receives push: "Time for your Dolo 650"→ Taps notification → opens TrackerScreen
