Edge Cases + Friction Points
F1
Illegible handwriting — OCR fails partially
Show partial decode card with explicit "Unrecognised fields" flagged in red. Never fill-in-the-blank with guesses. Ask user to manually confirm or retype uncertain fields before activation.
F2
Parent refuses to show prescription to child
Patient can be primary user; caregiver requests "read access." Privacy-first family model. Never force data sharing as a prerequisite.
F3
Doctor changes prescription mid-course
New Rx upload triggers "supersede" flow. Old meds show as "modified/stopped." Audit trail preserved. No medication can be auto-deactivated — always a human confirmation gate.
F4
Multiple caregivers for same patient (siblings)
One admin (primary caregiver) per patient. Others as co-caregivers. Dose mark by one → visible to all. Conflict resolution: latest mark wins, timestamped. Audit log shows who marked.
F5
SOS / PRN medications — "only if needed"
Separate SOS tracker card. Not scheduled. Logged when taken with timestamp. Shown in adherence context not as missed. Clear UX distinction from regular schedule.
03 — Trust Architecture
The OCR Trust Ladder

Swasthi's core trust promise: Interpret → Explain → Verify. Never auto-decide. Every automated step has a human gate before it affects a patient's medication.

01
Interpret
OCR reads prescription image. Raw text extracted. Confidence score computed per field (drug name, dose, frequency, duration).
never: auto-correct low-confidence fields
02
Explain
Convert extracted data into plain-language decode card. "Tab 1 – OD – After Food – 30 days" → "Take 1 tablet once a day, after eating, for 30 days." Terminology mapped (OD, BD, TDS, SOS, AC, PC).
never: explain without showing original text side-by-side
03
Verify (human gate)
Caregiver or patient must confirm decode card is accurate before any medication is activated. Editable fields. "Does this look right?" with explicit Yes/Edit options.
never: skip verify gate even if confidence is 100%
04
Activate
Only after verification. Medication enters schedule. DDC tracking begins. Audit log entry created with verifier's user ID and timestamp.

07 — Risk Analysis
Why Swasthi Could Fail
F1
OCR trust collapse
One wrong decode that a patient acts on causes harm. Even without clinical harm, the perception of "Swasthi gave wrong medicine info" ends the company. OCR must be treated as advisory, never prescriptive.
Fix: Trust ladder is non-negotiable. Human verify gate on every single medication activation. Show OCR confidence score. Flag every uncertain field.
F2
Low Day-7 retention — the "it's enough" drop
User uploads one prescription, understands it, feels done. Returns to WhatsApp reminders. Swasthi doesn't survive as a one-time decode tool — it needs daily presence.
Fix: Dose tracker must be sticky Day 1. The daily "mark taken" action is the retention mechanism, not the Rx decode. Design tracker as primary homescreen.
F3
Becoming a pharmacy or getting perceived as one
Any "buy now," "order refill," or "sponsored" feature destroys the neutral trust layer. Doctor trust also collapses if Swasthi is seen as pushing products.
Fix: Strict feature boundary. Refill alert = "it's time to refill" — never a button to a pharmacy. Let the user choose HOW they refill.
F4
Overbuilding before PMF validation
Lab reports, vitals, drug interactions, doctor booking — all great ideas that dilute focus. V1 ships in 90 days or dies in planning.
Fix: Honour the feature boundary. Ship MVC: Rx decode + schedule + DDC. Everything else is a V2 hypothesis.
F5
Wrong user target — patient vs caregiver mismatch
If the app is designed for the patient (65yo parent) to use alone, onboarding friction will be fatal. The primary user is the adult child, not the patient.
Fix: Caregiver-first UX. Patient mode is a simplified companion view. All governance, decode, and setup flows are designed for the 28–40yo adult child.
F6
No monetisation path before runway runs dry
Free forever is not a business. But charging too early kills growth. The monetisation window is tight.
Fix: Family plan subscription (₹199–399/month for 3+ family members) introduced at Day 61. Freemium: 1 patient free, family plan paid. Validate willingness-to-pay by Day 30 via conversations.
08 — Competitive Moats
Swasthi's Moats
Prescription literacy
India-specific terminology database (OD/BD/TDS, Ayurvedic scripts, regional handwriting patterns). Gets better with every decoded Rx. Data moat compounds.
Family governance
Multi-caregiver governance layer. No Indian health app has this. WhatsApp groups are the current competition — Swasthi formalises what families already do informally.
DDC algorithm
Dose continuity controller — treatment gap risk scoring. Unique, patentable, deeply embedded in chronic care workflows. Impossible to replicate without longitudinal adherence data.
India-first UX
Designed for Indian prescription formats, brand names, handwriting, and multi-lingual terminology. Not a Western app localised. Built India-first from schema to UX.
Neutral trust layer
Not a pharmacy. Not a doctor. Not an insurer. Swasthi is the only entity that helps families understand WITHOUT a commercial agenda. Rare and hard to fake once established.

10 — Final Verdict
Can Swasthi become India's default
Family Medication OS?
"Can Swasthi become India's default Family Medication Operating System?"
Yes — conditionally.
  • IF the OCR trust ladder is never compromised. One safety failure ends the company.
  • IF Swasthi remains a neutral layer — not a pharmacy, not a doctor, not a diagnostician.
  • IF family governance (multi-caregiver + roles) is the core experience, not a feature.
  • IF DDC becomes the default way Indian families think about medication continuity.
  • IF Day-7 retention crosses 60% by Day 60 — proving daily habit, not one-time utility.
  • IF the 90-day roadmap ships as scoped — no feature creep, no distraction.
  • IF Swasthi is built with the discipline to be the Family Chief Health Officer's single source of truth — not an app, but infrastructure.
India has 750M+ people managing chronic disease at home. Every family with a parent on BP / diabetes / thyroid medication is a potential Swasthi family. The market is not a niche — it is the entire Indian middle class.

The wedge is prescription confusion. The moat is prescription literacy + family governance. The business is chronic care infrastructure.

Swasthi does not need to win all of healthcare. It needs to own the 12-inch strip of territory between "doctor prescribes" and "patient takes medicine" — and make that strip so valuable, so trusted, so data-rich that no one can displace it.
